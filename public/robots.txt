# A crawler obeys only the most specific group that names it, and groups are
# never merged. Separate "Allow: /" groups per bot therefore exempted Googlebot,
# Bingbot and every AI crawler from the Disallow rules under "*". Every crawler
# is listed in ONE group below so they all get the same rules.
#
# The hero videos are a decorative background, not watch-page videos. Blocking
# them stops the "Video isn't on a watch page" report in Search Console and saves
# crawlers fetching assets they can never index (desktop and mobile renditions,
# each as WebM with an MP4 fallback).
#
# /admin, /auth, /reset-password and /banner-manager are NOT disallowed here on
# purpose: nginx sends them with X-Robots-Tag: noindex, and Google can only see
# that header on a page it is allowed to crawl. Blocking them here would leave
# a linked URL indexable as a bare address.
